# Portfolio Analyzer

A personal, locally-run dashboard that analyses your **Groww** stock and mutual fund holdings and gives rule-based **Buy / Hold / Sell** signals with the reasons shown. It also screens NSE stocks for new ideas and syncs results to Google Sheets.

> **Signals are generated by rules from public data. This is not investment advice. Consult a SEBI-registered investment adviser before acting.**
>
> This app never asks for broker logins and never places trades. Data comes only from files you export or a Google Sheet you share.

## Quick start (no Docker)

Prerequisites: [uv](https://docs.astral.sh/uv/) and Node 20 (via [nvm](https://github.com/nvm-sh/nvm)).

1. `curl -LsSf https://astral.sh/uv/install.sh | sh`
2. `curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash && nvm install 20`
3. `make setup` installs Python 3.12 + dependencies, runs `npm ci`, and creates `.env`
4. `make dev`
5. Open http://localhost:5173. API docs are at http://localhost:8000/docs

## Quick start (Docker)

1. `cp .env.example .env`
2. `docker compose up --build`
3. Open http://localhost:5173

If port 8000 or 5173 is already in use, set `BACKEND_PORT` / `FRONTEND_PORT` in `.env`.

## Importing your holdings

See [docs/GROWW_EXPORT_GUIDE.md](docs/GROWW_EXPORT_GUIDE.md). To try the app without your own data, import the **fake** files in `sample_data/`.

## Configuration

- **`backend/config/profiles.yaml`**: every threshold (styles, risk levels, signal bands, screener limits, tax rates). It is validated at startup, so a typo stops the app with a clear message instead of producing wrong signals.
- **`.env`**: paths, ports and log level. Secrets (the Google service-account JSON) go in `secrets/`, which is gitignored.

Your data lives in `backend/var/app.db` (or the `appdata` Docker volume). It is never committed.
